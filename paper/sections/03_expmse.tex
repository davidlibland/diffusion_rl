\section{The problem with exponential-space squared error}
\label{sec:03_expmse}

The value $\Vf(x,t)=\log\E_{\Base}[e^{r(X_1)}\mid X_t=x]$ is a conditional
log-partition function, and the H-martingale property (\S\ref{sec:02_setting})
supplies \emph{conditionally unbiased} targets in \emph{exponential} space:
$e^{\Vf(x_t)}=\E[e^{q}\mid x_t]$ for a one-step target $q$ (the terminal
reward, or a bootstrapped value). A network predicts the value in log space,
$p=\Vf_\theta(x_t)$; matching $e^{p}$ to the unbiased target $e^{q}$ with
squared error gives
\begin{equation}
  L_{\mathrm{MSE}}(p,q)=\big(e^{q}-e^{p}\big)^2,
  \qquad
  \frac{\partial L_{\mathrm{MSE}}}{\partial p}=2e^{p}\big(e^{p}-e^{q}\big)
    =2e^{2p}-2e^{p+q}.
  \label{eq:mse-grad}
\end{equation}
Both tails are pathological, but asymmetrically so
(Fig.~\ref{fig:loss_curves}, left).

\paragraph{Over-prediction explodes (recoverable).}
As $p\to+\infty$ the gradient grows like $2e^{2p}$ and overflows single
precision once $p\gtrsim 44$ nats (the square needs $e^{2p}$). This is a
nuisance but a benign one: the gradient merely needs to be a full-size,
correctly-signed step, so saturating it to a large finite value (or clipping)
recovers a usable update.

\paragraph{Under-prediction vanishes (unrecoverable).}
As $p\to-\infty$ the gradient behaves like $-2e^{p+q}\to 0$. This is exactly
the regime where the model is \emph{most wrong}: it assigns near-zero value
$e^{p}\approx 0$ to a state whose true value $e^{q}$ is large --- a rare,
high-reward target it has failed to find. The learning signal there is not
merely ill-scaled, it is \emph{absent}, and no amount of gradient clipping \citep{pascanu2013difficulty} can
manufacture a gradient that has decayed to zero. In the high-dimensional,
signal-sparse regime of \S\ref{sec:06_sparsity_onpolicy}, where the useful
targets are precisely the rare large ones, this is the dominant failure mode.

\paragraph{Why not regress in log space?}
The obvious escape is to drop the exponentials and fit $(p-q)^2$ directly,
which is perfectly conditioned. It is also biased. Squared error in $q$ is
minimized by $\E[q\mid x_t]$, whereas the value is
$\Vf=\log\E[e^{q}\mid x_t]$; by Jensen the two differ by the log-partition gap
\begin{equation}
  \Vf(x_t)-\E[q\mid x_t]\;=\;\log\E\big[e^{q-\E[q]}\big]\;\ge\;0,
  \qquad \approx \tfrac12\mathrm{Var}(q\mid x_t)\ \text{for small spread,}
  \label{eq:jensen-gap}
\end{equation}
and this gap is \emph{largest} in exactly the heavy-tailed, high-dimensional
regime the method is meant to handle: it is the quantity that a soft-max is all
about, so discarding it discards the signal. Unbiasedness pins us to the
exponential-space target; only the divergence applied to it is negotiable. That
is the opening the Bregman family exploits (\S\ref{sec:04_bregman}).

\paragraph{Empirical pathology.}
Beyond the asymptotics, the finite-precision behavior is severe; the
overflow-avoidance patterns we rely on are standard
\citep{blanchard2021logsumexp}. In our
convergence runs the naive loss skipped or aborted a large fraction of batches
on overflow --- in one FBRRT run, $18\%$ of batches once predictions reached
moderate magnitude --- and a \emph{single} non-finite prediction propagated
through the shared value network to poison every subsequent batch. We report
the full stability audit in \S\ref{sec:05_offpolicy_exp}. A stabilized
implementation with the exact gradient of \eqref{eq:mse-grad} saturated to the
float range (our \texttt{exp\_mse}) removes the overflow and the poisoning, and
it is the baseline we compare against throughout, so that the comparison
isolates the divergence rather than the arithmetic. What it cannot remove is
the vanishing gradient, which is a property of the divergence itself.

\paragraph{Prior fixes rescale the target; we cannot.}
Badly-scaled value regression is a known problem in reinforcement learning, and
the standard remedies transform the target: adaptive normalisation
\citep{vanhasselt2016popart}, an invertible square-root rescaling
\citep{pohlen2018observe}, or replacing regression by classification over
bins \citep{farebrother2024stopregressing}. Each conditions the problem by
changing what is regressed. None is available here, because each destroys the
one property \eqref{eq:unbiased-target} gives us --- that the target is
unbiased for $e^{\Vf}$ --- and with it the guarantee that the minimiser is the
value. That constraint is what forces the fix into the divergence.
